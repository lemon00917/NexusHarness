# 提示词前端可配置化设计方案

## 1. 需求背景

当前 Prompt 硬编码在 `prompts.py` 中：
- 系统提示模板写死在代码里
- 医学场景提示无法动态切换
- RAG 注入参数无法运行时调整

**目标**：通过前端界面配置提示词模板和参数，无需修改代码。

---

## 2. 设计方案

### 2.2 管理接口

```python
# web/app.py 或新文件 microharness/config/prompt_config.py

PROMPT_CONFIG_FILE = Path("config/prompts.json")

def load_prompt_config() -> dict:
    """加载提示词配置"""
    if not PROMPT_CONFIG_FILE.exists():
        return get_default_prompt_config()
    return json.loads(PROMPT_CONFIG_FILE.read_text(encoding="utf-8"))

def save_prompt_config(config: dict) -> None:
    """保存提示词配置"""
    PROMPT_CONFIG_FILE.parent.mkdir(exist_ok=True)
    PROMPT_CONFIG_FILE.write_text(
        json.dumps(config, ensure_ascii=False, indent=2),
        encoding="utf-8"
    )

def get_default_prompt_config() -> dict:
    """返回默认提示词配置"""
    return {
        "system_prompt": {
            "base_template": "...",
            "variables": {...}
        },
        "medical_prompts": {...},
        "memory": {"max_records": 5, "enabled": True},
        "rag": {"auto_inject": True, "top_k": 2, "timeout_ms": 500}
    }
```

### 2.3 前端 API

```python
# web/app.py

@app.get("/api/config/prompts")
async def get_prompt_config():
    """获取提示词配置"""
    return load_prompt_config()

@app.post("/api/config/prompts")
async def update_prompt_config(request: Request):
    """更新提示词配置"""
    config = await request.json()

    # 验证配置格式
    if not validate_prompt_config(config):
        return {"error": "Invalid prompt configuration"}

    save_prompt_config(config)
    return {"status": "saved", "config": config}

@app.get("/api/config/prompts/templates")
async def list_prompt_templates():
    """列出可用模板"""
```

### 2.4 动态 Prompt 组装

```python
# microharness/config/prompts.py

def get_system_prompt(
    task: str = None,
    tools: list = None,
    intent: str = None,  # 新增：意图类型
) -> str:
    config = load_prompt_config()

    # 构建变量值
    variables = {
        "tool_block": build_tool_block(tools),
        "rule_block": config["system_prompt"]["variables"]["rule_block"],
        "workspace": config["system_prompt"]["variables"]["workspace"],
    }

    # 替换模板变量
    template = config["system_prompt"]["base_template"]
    base = template.format(**variables)

    # 意图匹配 → 使用对应场景提示
    if intent and intent in config["medical_prompts"]:
        prompt_config = config["medical_prompts"][intent]
        if prompt_config.get("enabled"):
            base = prompt_config["template"].format(
                query=task or "",
                medical_knowledge=_get_medical_knowledge(task, prompt_config) if prompt_config.get("auto_inject_rag") else ""
            )

    # RAG 注入
    if config["rag"]["auto_inject"] and task:
        rag_results = _get_rag_with_timeout(task, config["rag"])
        if rag_results:
            base += f"\n\n## 知识库检索结果\n{rag_results}"

    # 记忆注入
    if config["memory"]["enabled"]:
        memories = load_memories()
        memory_block = format_memories_for_prompt(memories, config["memory"]["max_records"])
        if memory_block:
            base += f"\n\n{memory_block}"

    return base
```

## 6. 可行性评估

| 评估项 | 结论 |
|--------|------|
| 实现复杂度 | 中等（1-2 天） |
| 前端工作量 | 中等（配置页面 + API 对接） |
| 灵活性 | 高（运行时调整提示词） |
| 与医疗知识库配合 | 好（意图 → 模板 → RAG 一体化） |

**结论：提示词前端配置化可行，且能显著提升系统的灵活性和易用性。建议与医疗知识库模块同期开发。**
