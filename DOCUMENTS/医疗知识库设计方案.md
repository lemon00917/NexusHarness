## 2. 方案核心思路

**在现有 RAG 基础上扩展**，创建独立的医学知识库：

```
ChromaDB
├── documents (现有)         → 通用 RAG
└── medical_knowledge (新建) → 医学 RAG
```

**复用点**：
- `document_parser.py` → 扩展医学类型识别
- `chunker.py` → 扩展医学分块策略
- `rag.py` 架构 → 复用为 `MedicalRAG` 类

### 4.2 医学类型识别（扩展 doc_parser.py）

```python
# microharness/medical/doc_parser.py

from microharness.rag.document_parser import parse_document as generic_parse

# 医学章节标记
MEDICAL_SECTION_MARKERS = {
    "药品": ["【药品名称】", "【适应症】", "【用法用量】", "【禁忌】", "【不良反应】"],
    "指南": ["【指南】", "【推荐意见】", "【证据级别】"],
    "检验": ["【参考值】", "【临床意义】", "【标本采集】"],
    "手术": ["【术前准备】", "【手术步骤】", "【术后处理】"],
}

def detect_medical_type(content: str) -> str:
    """自动识别文档类型"""
    for doc_type, markers in MEDICAL_SECTION_MARKERS.items():
        if any(m in content for m in markers):
            return doc_type
    return "general"

def parse_medical_doc(content: bytes, filename: str) -> tuple[str, str]:
    """
    解析医学文档。
    Returns: (parsed_text, medical_type)
    """
    text = generic_parse(content, filename)
    medical_type = detect_medical_type(text)
    return text, medical_type
```

### 4.3 医学分块策略（扩展 chunker.py）

```python
# microharness/medical/chunker.py

from microharness.rag.chunker import chunk_by_length, chunk_by_chapter

def chunk_medical(text: str, mode: str = "auto", medical_type: str = "general") -> list[str]:
    """
    医学文档分块。

    Args:
        mode:
            - "auto": 根据类型自动选择（药品/指南用 section，普通用 length）
            - "section": 按医学章节分块
            - "length": 按长度分块
    """
    if mode == "auto":
        if medical_type in ("药品", "指南"):
            mode = "section"
        else:
            mode = "length"

    if mode == "section":
        sections = split_by_medical_sections(text, medical_type)
        if len(sections) > 1:
            return sections

    return chunk_by_length(text, chunk_size=1500, overlap=200)

def split_by_medical_sections(content: str, medical_type: str) -> list[str]:
    """按医学章节标记分割"""
    markers = MEDICAL_SECTION_MARKERS.get(medical_type, [])
    if not markers:
        return [content]

    sections = []
    current = []
    for line in content.split('\n'):
        if any(line.strip().startswith(m) for m in markers):
            if current:
                sections.append('\n'.join(current))
                current = []
        current.append(line)

    if current:
        sections.append('\n'.join(current))

    return sections if sections else [content]
```

### 4.4 Agent 工具

```python
# microharness/medical/tools.py

from langchain_core.tools import tool

@tool
def medical_lookup(query: str, category: str = None) -> str:
    """
    检索医学知识库。

    Args:
        query: 查询内容（药品名称、检验指标、疾病名称等）
        category: 可选筛选（药品/指南/检验/手术）
    """
    from microharness.medical import medical_kb

    results = medical_kb.search(query, top_k=3, filter_type=category)

    if not results:
        return "未找到相关医学知识。"

    lines = ["## 医学知识检索结果\n"]
    for i, doc in enumerate(results, 1):
        doc_type = doc.metadata.get("medical_type", "未知")
        lines.append(f"【{i}】[{doc_type}]")
        lines.append(f"{doc.content[:400]}...\n")

    return "\n".join(lines)
```
