# NexusHarness 知识库示例文档

本目录用于存放自定义知识库文档，可通过 Web UI 的 RAG 知识库页面上传和管理。

## 文档格式

支持以下格式的文档：
- `.txt` - 纯文本文件
- `.md` - Markdown 文件
- `.json` - JSON 文件
- `.py` - Python 代码文件
- `.js` - JavaScript 代码文件
- `.html` - HTML 文件
- `.css` - CSS 文件

## 使用方式

1. 访问 `/templates/rag.html` 打开 RAG 管理页面
2. 点击"上传文档"按钮选择文件
3. 上传后文件会自动索引到知识库
4. 在 Agent 对话框中提问时，相关文档内容会自动注入到上下文

## 示例场景

- 项目架构文档：描述系统设计、模块关系
- API 文档：接口说明、参数定义
- 最佳实践：编码规范、配置指南
- 问题排查手册：常见错误及解决方案
